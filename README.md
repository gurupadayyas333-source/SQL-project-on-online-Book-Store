# SQL Online Book Store Project

## Overview

This project demonstrates the design and analysis of an Online Book Store database using PostgreSQL. The database consists of three main tables: **Books**, **Customers**, and **Orders**, which simulate real-world bookstore operations. The project covers database creation, table relationships, data management, and business analysis through SQL queries.

## Project Objectives

* Design a relational database for an online bookstore.
* Create and manage tables with primary and foreign key relationships.
* Perform data retrieval, filtering, aggregation, and reporting using SQL.
* Generate meaningful business insights from bookstore sales data.

## Database Schema

### Books

Stores information about books, including title, author, genre, publication year, price, and stock.

### Customers

Maintains customer details such as name, email, phone number, city, and country.

### Orders

Tracks customer purchases, order dates, quantities, and total order amounts.

## SQL Concepts Applied

* Database and table creation (DDL)
* Data retrieval using SELECT statements
* Filtering with WHERE conditions
* Sorting and limiting results
* Aggregate functions (SUM, AVG, COUNT)
* INNER JOIN and LEFT JOIN operations
* GROUP BY and HAVING clauses
* Revenue and sales analysis
* Inventory management queries

## Key Business Insights

* Total revenue generated from book sales
* Most frequently ordered books
* Best-selling genres and authors
* Customer purchase behavior analysis
* Top-spending customers
* Remaining stock after order fulfillment
* Average book prices by genre
* Geographic distribution of customers

## Skills Demonstrated

* PostgreSQL
* Relational Database Design
* Data Analysis with SQL
* Query Optimization
* Business Intelligence Reporting
* Data Aggregation and Joins

## Project Outcome

This project showcases how SQL can be used to manage and analyze bookstore operations efficiently. It highlights practical database concepts and demonstrates the ability to extract actionable insights from structured data, making it an excellent portfolio project for aspiring Data Analysts and SQL Developers.
